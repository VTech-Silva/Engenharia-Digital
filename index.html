Como o recálculo funciona

Quando uma tarefa incompleta passa da data final, o cronograma move seu início para hoje. As sucessoras respeitam as predecessoras cadastradas, inclusive ligações entre TRs, e são empurradas automaticamente. Durações fracionárias são arredondadas para cima em dias corridos nesta projeção. A data de 26/10 permanece fixa; o painel alerta se a projeção ultrapassar o marco.

Os alertas aparecem ao abrir esta página. Para notificações do navegador, permita a autorização no botão acima e mantenha a página aberta. GitHub Pages não envia alertas se o navegador estiver fechado. Use Exportar backup para guardar os dados antes de trocar de computador; o localStorage não é sincronizado entre casa e trabalho.
