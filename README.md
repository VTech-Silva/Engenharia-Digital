# Plano de ataque — TR-2036KS

Este pacote contém a página pronta para ser colocada na raiz de um repositório GitHub Pages.

## Conteúdo
- index.html
- styles.css
- app.js
- assets/logo-enesa.png
- assets/logo-vale.png

## Publicar
Extraia este ZIP dentro da pasta local do repositório ou envie os arquivos extraídos para a raiz do repositório. Confirme que index.html, styles.css e app.js ficam juntos na raiz e que a pasta assets também está na raiz.
No GitHub, abra Settings → Pages. Em Build and deployment, escolha Deploy from a branch, selecione main e a pasta /(root), depois salve.

## Dados e notificações
As alterações ficam salvas no armazenamento local do navegador. Para levar os dados a outro computador, use Exportar backup e depois Importar backup. Notificações do navegador só aparecem enquanto a página estiver aberta. GitHub Pages não envia alertas em segundo plano.
